# Chat Backend (Hapi + Prisma + MySQL) — Starter Boilerplate

A production-oriented starter backend for a WhatsApp-like chat application with an AI chat option. Built with Hapi.js, Prisma (MySQL), JWT authentication, Google OAuth support and a pluggable AI service.

---

## Features

- Clean enterprise-grade folder structure
- Email/password + Google OAuth logins
- JWT-based access + refresh tokens
- Sessions table to manage/invalidate refresh tokens
- Prisma ORM + raw SQL support (mysql2)
- Hapi server with swagger docs
- AI service wrapper (OpenAI-ready)
- Basic Jest test setup
- Example routes for chat and AI

---

## Tech stack

- Node.js
- Hapi.js
- Prisma ORM (MySQL)
- mysql2 (raw SQL)
- JWT (hapi-auth-jwt2)
- OpenAI-compatible AI wrapper
- Jest + Supertest for tests
- hapi-swagger for docs
